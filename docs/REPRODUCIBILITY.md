# Reproducibility guide

From the repository root, install `requirements.txt` and run the commands in the README. The tested environment used Python 3 and python-flint 0.9.0. All verifier entry points use the explicit step-two construction. The preserved historical engine defaults to step four; current callers explicitly request step two.

## Current entry points

- `verification/qbeta.py`: exact rational moments, adapted from `qbeta2-audit/source/step2.py` with only a provenance docstring added.
- `verification/replay.py`: exact determinant polynomial, explicit conservative cyclotomic clearer, content extraction, integer-coefficient checks, examples, and optional large interval.
- `verification/independent_content.py`: separate standard-library `Fraction` determinant evaluation and interpolation; adapted from the source with its output path changed.
- `verification/independent_functional.py`: independent direct functional and positive-series target evaluation, determinant evaluations, primitive-polynomial intervals; adapted with a local import and output path.
- `verification/check_sources.py`: local SHA-256 and Git-blob identity checks against the commit-pinned manifest.

Certificate coefficient arrays are in ascending degree order. Rational coefficients use exact fraction strings. The primitive polynomial removes the positive gcd of the integer coefficients after clearing denominators; it need not have positive leading coefficient. The safe normalization in the manuscript is different and is tested separately.

The large coefficient fingerprint is SHA-256 of the ASCII comma-separated primitive coefficients in ascending order, with no spaces and no final newline. All coefficients are regenerated by `replay.py --large`; no enormous coefficient file is required.

Each stored Arb interval includes a rigorous radius. The decimal `logabs` is a diagnostic float and not a certified inequality. Wall-clock `seconds` fields in the functional replay are diagnostic and vary on rerun. The all-index proof does not depend on certificate timing, signs observed in a finite range, or floating-point values of the constants.

## Build and review

`make paper` runs pdflatex twice in `paper/`. Source files are `main.tex`, `introduction.tex`, and `references.tex`. The included PDF was visually inspected on every page and the final build had no overfull boxes or unresolved references. PDF bytes can differ on rebuild because of timestamps.

The GitHub workflow runs the finite checks and paper build after publication. It is included as configuration; no remote CI success is claimed before that workflow actually runs. It deliberately does not label its result as formal theorem verification.

The original 29 source files remain unchanged. Some historical scripts use neighboring paths or represent the step-four precursor; they are archival evidence, not the recommended reproduction entry points.
